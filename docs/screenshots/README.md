## 截圖規範

- 格式：**PNG**
- 寬度：1200-1600px
- 內容：只截重點區塊，不要整個瀏覽器
- 隱私：**模糊真實客戶名 / email / shop_id**
- 工具：Win+Shift+S / Cmd+Shift+4 / ShareX / Lightshot

詳細見 `使用說明書.md` 附錄 B。
