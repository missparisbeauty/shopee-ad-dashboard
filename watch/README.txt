📂 蝦皮 CSV 自動上傳資料夾
================================

【怎麼用】

1. 在這個 watch/ 資料夾下，為每個店家建一個子資料夾
   範例：
     watch/S001/                  ← 店家編號
     watch/自家3C旗艦店/          ← 中文也可以
     watch/A 食品行/

2. 從蝦皮賣家中心 → 行銷中心 → 廣告報表 → 匯出 CSV
   把 CSV 拖進對應的子資料夾即可

3. server.py 啟動後會每 5 秒自動掃描
   - 處理成功 → 移到 watch/{shop}/processed/，資料即時併入儀表板
   - 處理失敗 → 移到 watch/{shop}/failed/，原檔保留方便排查

4. 在儀表板「整合與設定」頁，可看到「📂 資料夾自動上傳」面板
   - 啟用 / 停用切換
   - 立即掃描（不等 5 秒週期）
   - 各 shop 的 待處理 / 已處理 / 失敗 數量
   - 最近 10 筆處理紀錄

【子資料夾命名規則】

允許：
  ✓ 中英數、空白、底線、連字號、括號、中文
  ✓ 例：S001、自家3C旗艦店、A 食品行 (主店)

禁止（會被略過、不處理）：
  ✗ 路徑符號 / \
  ✗ 引號、控制字元、換行
  ✗ 名稱以 . 開頭
  ✗ 名稱叫 processed 或 failed（系統保留）

【支援的檔案格式】

  ✓ .csv / .tsv / .txt
  ✓ 編碼：UTF-8 (含 BOM) / BIG5 / CP950 / GB18030
  ✓ 大小：最大 50 MB
  ✓ 格式：蝦皮賣家中心匯出的廣告報表（中英文 header 都支援）

【手動關閉自動掃描】

  1. UI：「整合與設定」→「📂 資料夾自動上傳」→ 點「⏸ 停用」
  2. API：POST http://localhost:8765/api/v1/watcher/stop
  3. 直接停 server 也會自動停止

【已處理過的檔案】

  自動移到 watch/{shop}/processed/ 並加上時間戳避免同名覆蓋
  例：2026-04-25.csv → 2026-04-25.20260503-145812.csv
  你可以隨時手動刪除 processed/ 裡的舊檔
